# Project workflow
Read README.md, docs/PROJECT_STATE.md and docs/Execution_Log.md before resuming.
Preserve existing work. Cite verified research; distinguish product claims from independently measured results.
Never describe synthetic data as Cynbit data. Run pytest and evaluation after model changes.
Commit meaningful milestones and immediately push to origin; verify remote HEAD. Never force push.
Do not publish, submit the assessment, email recruiters, or change repository visibility.
Keep logs and state current. Log previous commit hashes in the next milestone to avoid recursive commits.
